# Universal Agent Rules

[简体中文](README.md) · [Changelog](CHANGELOG.md) · [Contributing](CONTRIBUTING.md) · [License](LICENSE)

One ruleset, every AI coding assistant. Write your rules **once** in `core/`; a build script renders them
into each platform's expected location, so Claude Code, Codex, Cursor, Trae, OpenClaw/WorkBuddy, ChatGPT
and Doubao all read the same conventions — **no duplicated maintenance**.

## Platform matrix

| Platform | Reads | Artifact here | Hard limit |
|---|---|---|---|
| **Claude Code** | `CLAUDE.md` (repo root), `.claude/rules/`, `.claude/skills/` | `CLAUDE.md` (`@AGENTS.md` + Claude-specific) | < 200 lines per file recommended |
| **Codex** (CLI / cloud) | `AGENTS.md` (root → cwd), `~/.codex/AGENTS.md` | `AGENTS.md` (single source of truth) | 32 KiB combined |
| **Cursor** | `.cursor/rules/*.mdc` (Agent mode reads only `.mdc`); also honors `AGENTS.md` | `.cursor/rules/core.mdc` | plain `.md` in rules dir is ignored |
| **Trae** | `.trae/rules/*.md`; optionally `AGENTS.md` / `CLAUDE.md` | `.trae/rules/core.md` | ≤ 20000 bytes total |
| **OpenClaw / WorkBuddy** | `skills/<name>/SKILL.md`, `.agents/skills/` | `skills/ai-agent-rules/SKILL.md` | frontmatter needs `name`, `description` |
| **ChatGPT** | Settings → Personalization → Custom Instructions (2 fields) | `chatgpt/field1.txt`, `field2.txt` | **1500 characters per field** |
| **Doubao (bot)** | Bot persona prompt + knowledge base | `doubao/persona.md` + upload `core/*.md` | follow the UI hint |
| GitHub Copilot (bonus) | `.github/copilot-instructions.md` | copy `AGENTS.md` | — |

## Quick start

```bash
curl -O https://raw.githubusercontent.com/Marlboro90/universal-agent-rules/main/AGENTS.md
curl -O https://raw.githubusercontent.com/Marlboro90/universal-agent-rules/main/CLAUDE.md
# ChatGPT: paste chatgpt/field1.txt into field 1, field2.txt into field 2
# OpenClaw / WorkBuddy: drop skills/ai-agent-rules/ into skills/ or .agents/skills/
```

Then customize `core/` and run `python3 scripts/build.py`.

## Why one source of truth

`core/` is handwritten; every platform file is generated by `scripts/build.py` and committed, so users can
copy files without running anything. CI runs `python3 scripts/build.py --check` to fail the build if a
generated file ever drifts from `core/`.
