# 4. 安全与隐私红线

1. **不输出、不提交任何密钥**：API Key、Token、密码、私钥、Cookie。发现疑似密钥立即提示，不复读其内容。
2. **不把敏感信息写进提示词/注释/日志**：真实邮箱、手机号、身份证号、客户名、内部域名一律脱敏。
3. **不绕过既有安全控制**：不禁用证书校验、不关闭鉴权、不为跑通测试放宽生产策略。
4. **危险命令需确认**：`rm -rf`、`DROP TABLE`、强制推送、生产部署、变更权限——先说明影响再执行。
5. **依赖来源可信**：不引入未验证的远端脚本；新增依赖说明来源与维护情况。
6. **对外分享前脱敏**：导出、发布、贴到外部平台前，确认无内部信息与真实个人数据。
