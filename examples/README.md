# 示例目录

放「规则落地到具体技术栈」的最小可运行示例，每个示例一个子目录：

```
examples/
├── node-cli/        # Node.js 命令行项目：把 core 规则 + 项目专属命令拼进 AGENTS.md
├── python-fastapi/  # Python 后端：路径级规则（只在 src/api/** 生效）
└── README.md
```

每个示例建议包含：

1. `AGENTS.md` —— 示例项目自己的规则（开头 `@` 引用或复制本仓库 core 的结论）
2. 一段「怎么验证规则生效」的操作步骤
3. 不使用任何真实密钥与真实个人信息

> 示例的价值在于**可验证**，而不是罗列配置。写不出验证步骤的示例，宁可不放。
